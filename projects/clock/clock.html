Digital Clock Using Logic Gates

Electronics / Digital Logic
Logic Gates 7-Segment Displays 74LS90 NE555 74LS47

Overview

Designed and implemented a fully functional 24-hour digital clock using TTL logic integrated circuits and 7-segment displays as part of an Electronics course project. The system was built entirely without microcontrollers, demonstrating core principles of digital electronics, sequential logic design, and timing systems.

My Role & Implementation

This was a solo project where I independently designed, simulated, and built the entire system. The design was first verified using Proteus simulation, then implemented on breadboards using TTL ICs. I was responsible for circuit design, component selection, system integration, debugging, and final testing.

The clock was constructed using cascaded counter stages for seconds, minutes, and hours, with proper rollover logic for 24-hour operation. A NE555 timer configured with a potentiometer was used to generate a stable 1 Hz clock signal for real-time counting.

Technical Highlights

  • 74LS90 Decade Counters – Used for building cascaded BCD counters for seconds, minutes, and hours.
  • 74LS47 BCD-to-7-Segment Decoders – Drove six common-anode 7-segment displays for real-time visualization.
  • NE555 Timer (Astable Mode) – Configured with a potentiometer to generate a stable 1 Hz clock pulse.
  • 24-Hour Rollover Logic – Implemented using 74LS08 AND gate IC for correct reset at 23:59:59 → 00:00:00.
  • Manual Time Adjustment – Two pushbuttons were integrated to adjust hours and minutes independently.
  • Simulation & Hardware Implementation – Verified using Proteus before real hardware assembly on breadboards.

Challenges & Problem Solving

A major challenge was ensuring correct synchronization during rollover transitions between seconds, minutes, and hours. Initial issues were caused by propagation delays and unstable transitions in cascaded counters. This was solved by refining reset logic using 74LS08 gates and validating signal integrity across all stages.

Results

The final system successfully displayed real-time hours, minutes, and seconds using six 7-segment displays with stable 24-hour operation. The clock maintained accurate timing using a 1 Hz signal and operated reliably after extensive hardware testing.
